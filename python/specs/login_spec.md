# 画面仕様書：Login画面

## ■ 画面概要
ECサイト（SauceDemo）のログイン画面。ユーザー名とパスワードを入力し、
認証に成功すると商品一覧画面（Inventory）へ遷移する。
本画面は全機能の入口であり、未認証状態では他画面への直接アクセスは
できない前提とする。

対象URL：https://www.saucedemo.com/

---

## ■ 項目一覧

| 項目名 | 種別 | 表示ラベル |
|---|---|---|
| ユーザー名 | テキスト入力 | Username |
| パスワード | パスワード入力 | Password |
| ログインボタン | ボタン | Login |

---

## ■ 入力条件

| 項目 | 入力条件 |
|---|---|
| ユーザー名 | 半角英数字・アンダースコア。大文字小文字を区別する |
| パスワード | 半角英数字・記号。大文字小文字を区別する |

---

## ■ 必須項目

- ユーザー名：必須
- パスワード：必須

---

## ■ バリデーション

| ケース | 挙動 |
|---|---|
| ユーザー名未入力でログイン押下 | エラーメッセージ表示、画面遷移なし |
| パスワード未入力でログイン押下（ユーザー名は入力済み） | エラーメッセージ表示、画面遷移なし |
| 両方未入力でログイン押下 | エラーメッセージ表示（ユーザー名側のエラーが優先表示される） |
| 存在しないユーザー名 | エラーメッセージ表示、画面遷移なし |
| ユーザー名は正しいがパスワード誤り | エラーメッセージ表示、画面遷移なし |
| ロック済みユーザー（locked_out_user）でのログイン | 専用のエラーメッセージ表示、画面遷移なし |

---

## ■ ボタン動作

| ボタン | 動作 |
|---|---|
| Login | 入力値のバリデーション実行。成功時はInventory画面へ遷移。失敗時は画面遷移せず、エラーメッセージを表示する |

---

## ■ 画面遷移

- ログイン成功 → Inventory（商品一覧）画面へ遷移
- ログイン失敗 → Login画面に留まる
  - ユーザー名の入力値は保持される（実機確認済み）
  - パスワードの入力値保持有無は未確認（一般的なUIパターンとして
    非保持の可能性が高いが、要検証事項として残す）

---

## ■ エラーメッセージ（実機・複数の一次資料で確認済み）

| ケース | メッセージ文言 |
|---|---|
| ユーザー名未入力 | Epic sadface: Username is required |
| パスワード未入力 | Epic sadface: Password is required |
| 認証情報不一致 | Epic sadface: Username and password do not match any user in this service |
| ロック済みユーザー | Epic sadface: Sorry, this user has been locked out. |

---

## ■ 業務ルール

- ユーザー名・パスワードの組み合わせが正しく、かつロック状態でない場合のみ
  ログインを許可する
- ロックユーザーは、認証情報が正しくてもログインを許可しない
  （セキュリティ上のアカウント制御機能）
- ログイン成功時、以降の画面（Cart/Checkout/Logout）は認証状態を前提と
  した動作となる
