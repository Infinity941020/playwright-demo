# 画面仕様書：Checkout Step One画面（購入者情報の入力）

## ■ 画面概要
ECサイト（SauceDemo）の購入手続きの1画面目。購入者の氏名と郵便番号を入力し、
注文内容の確認画面（Checkout Step Two）へ進む。
本画面は認証済みであることが前提であり、未認証状態ではアクセスできない。

対象URL：https://www.saucedemo.com/checkout-step-one.html
対象ユーザー：standard_user
（problem_user等の特殊ユーザーは本仕様の対象外。今後の拡張候補とする）

TS版との対応：TS版の `pages/CheckoutPage.ts` のうち、Step One に関する部分に相当する画面。

実機確認：2026-11-08（Playwright調査用スクリプトにて確認）

---

## ■ 項目一覧

| 項目名 | 種別 | 表示内容 |
|---|---|---|
| 画面タイトル | テキスト | Checkout: Your Information |
| 名 | テキスト入力 | プレースホルダー「First Name」 |
| 姓 | テキスト入力 | プレースホルダー「Last Name」 |
| 郵便番号 | テキスト入力 | プレースホルダー「Zip/Postal Code」 |
| キャンセルボタン | ボタン | Cancel |
| 次へボタン | ボタン | Continue |
| エラー表示 | テキスト（帯） | 入力チェックでエラーになったときに表示。×ボタン付き |
| カートアイコン | アイコン（リンク） | 右上に表示。カート内件数をバッジで表示（0件のときは非表示） |

※ 入力欄には表示ラベルはなく、プレースホルダーのみが表示される。
※ カートの中身（商品名・価格など）は本画面には表示されない。
※ ヘッダーのメニュー（ハンバーガーメニュー）はLogout機能で扱うため、本仕様の対象外とする。

---

## ■ 必須項目

- 名：必須
- 姓：必須
- 郵便番号：必須

※ 文字種・文字数のチェックはない（郵便番号に数字以外を入れても、各項目に10000文字を入れてもエラーにならないことを実機確認済み）。

---

## ■ 入力チェック

Continue を押したときに、次の順で未入力をチェックし、最初に見つかった項目のエラーを1つだけ表示する。

| 優先順 | 未入力の項目 | エラーメッセージ |
|---|---|---|
| 1 | 名 | Error: First Name is required |
| 2 | 姓 | Error: Last Name is required |
| 3 | 郵便番号 | Error: Postal Code is required |

- エラーがあるときは画面遷移しない
- 優先順は、3項目の未入力の組み合わせ8通りすべてで実機確認済み
  （例：3項目すべて未入力のときは「Error: First Name is required」が表示される）
- 入力値を修正しただけではエラー表示は消えない。再度 Continue を押すと、
  残っている未入力項目のエラーに切り替わるか、未入力がなければ次の画面へ進む

### エラー表示を閉じる
- エラー表示の×ボタンを押すと、エラー表示（帯・入力欄の赤表示・×アイコン）がすべて消える
- 閉じても入力値は残る

---

## ■ 画面遷移

| 操作 | 遷移先 |
|---|---|
| 3項目を入力して Continue を押下 | Checkout Step Two画面（/checkout-step-two.html） |
| Cancel を押下 | Cart画面（/cart.html） |
| カートアイコンをクリック | Cart画面（/cart.html） |

※ 遷移先の画面（Step Two／Cart）の中身は本仕様の対象外。本仕様では「遷移すること」までを扱う。

---

## ■ 入力値の保持

| 操作 | 入力値 |
|---|---|
| エラー表示後、およびエラー表示を閉じた後 | 保持される |
| ページを再読み込み | 保持されない（空に戻る） |
| Step Two からブラウザの「戻る」で戻る | 保持されない |
| Cancel で Cart画面に戻ってから再度入る | 保持されない |

---

## ■ カートとの関係

- 本画面での操作（入力、エラー、再読み込み、Cancel、カートアイコン、Continue）では、
  カートの内容とバッジの件数は変わらない

---

## ■ 未ログイン時

- 未ログイン状態で /checkout-step-one.html に直接アクセスした場合、
  Login画面（https://www.saucedemo.com/）へ戻され、以下のエラーメッセージが表示される

| ケース | メッセージ文言 |
|---|---|
| 未ログインでのアクセス | Epic sadface: You can only access '/checkout-step-one.html' when you are logged in. |

---

## ■ 業務ルール

- 本画面はログイン済みのユーザーのみ利用できる
- 名・姓・郵便番号の3項目がすべて入力されている場合のみ、次の画面へ進める
- 入力値は、エラーが表示されても保持されるが、本画面を離れたり再読み込みしたりすると保持されない
- 本画面の操作はカートの内容に影響しない

---

## ■ 実機で確認したが、意図された仕様か不具合かを判断できない挙動

以下は事実として記録し、本仕様のテスト対象には含めない（扱いは別途判断）。

| 挙動 | 実機確認の結果 |
|---|---|
| 空白のみの入力 | 半角・全角スペースやタブだけを入力しても、未入力扱いにならず次の画面へ進める |
| 入力欄で Enter キーを押す | Continue ではなく Cancel が動き、Cart画面へ戻る（入力済みでも同じ） |
| エラー時の入力欄の赤表示 | 未入力の項目だけでなく、入力済みの項目も含めた3項目すべてが赤表示になり、×アイコンが付く |
| カートが空のとき | 本画面を表示でき、3項目を入力すれば Step Two へ進める（cart_spec.md の「カートが空の状態での Checkout」と同じ扱い） |
